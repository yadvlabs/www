# yadv labs

Source for [labs.yadv.in](https://labs.yadv.in), the home of yadv labs' experiments
and projects. The main site is [yadv.in](https://yadv.in).

Built with [Astryx](https://astryx.atmeta.com) (React 19 + StyleX design system)
and Vite, using Astryx's built-in **Stone** theme.

## Develop

```sh
npm install
npm run dev       # local dev server
npm run build     # typecheck + production build into dist/
npm run preview   # serve the production build
```

## Pages and projects

The site has three pages, each a Vite entry point:

- `/` (`index.html` → `src/pages/Home.tsx`): showcased projects, stealth
  placeholders, and panels leading to the other two pages
- `/work/` (`work/index.html` → `src/pages/Work.tsx`): projects built at
  other organisations
- `/old/` (`old/index.html` → `src/pages/Old.tsx`): open source
  contributions, old experiments from
  [yadvlabs/old](https://github.com/yadvlabs/old), and hacklab

All three share the header, footer and theme in `src/components/SiteShell.tsx`.
All content lives in [`src/projects.ts`](src/projects.ts). Images are in
`public/images/`.

## Theme

The site uses Astryx's built-in Stone theme, wired up by `src/astryx-themes.ts`
(generated by `npx astryx theme add stone`). To switch themes, install the theme
package, then run `npx astryx theme add <slug>` and `npx astryx theme use <slug>`.
The Astryx packages are pinned to the same version, so upgrade them together.

## Deploy

Deployed to https://labs.yadv.in with Cloudflare. Build command: `npm run build`, output directory: `dist`.
